# IT-Support-Portfolio
IT Support & Troubleshooting Portfolio

This repository demonstrates real-world IT support and troubleshooting scenarios commonly encountered in Tier 1 and Tier 2 technical support environments. Each entry simulates a help desk ticket, documenting issue identification, diagnostic steps, root cause analysis, and resolution.

The goal of this repository is to showcase my capabilities in handling practical IT problem-solving skills, structured troubleshooting methodology, and clear technical documentation.
